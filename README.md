🚗 Car Racing Game — HTML, CSS & JavaScript

An exciting browser-based Car Racing Game built using pure HTML, CSS, and JavaScript.
This project demonstrates interactive gameplay, smooth animations, and responsive UI design without using any external game engines.

🎮 Game Preview

👉 Fast-paced car racing experience
👉 Smooth controls & real-time movement
👉 Clean and colorful UI
👉 Lightweight and runs directly in the browser

✨ Features

✅ Smooth car movement controls
✅ Collision detection system
✅ Dynamic obstacle generation
✅ Score tracking system
✅ Responsive game layout
✅ Pure Vanilla JavaScript (No frameworks)
✅ Beginner-friendly project structure

🛠️ Tech Stack
HTML5 — Game Structure
CSS3 — Styling & Animations
JavaScript (ES6) — Game Logic & Interactivity
